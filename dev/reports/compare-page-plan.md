# The compare page: plan for the next session

Session 33, Oct 2, 2026. Written by Claude for Duke. Not built yet; this note is so the next session can start straight away.

## Why it was not built this session

The comparison that used to be on the page (saved in `dev/drafts/compare-designs.html`) was built on the v4.22 engine, where every design, Compassionism included, was paid for by a flat contribution on wages. v5.0's Compassionism is paid for by the Source, with what it pays out treated as new money. Putting v5.0 Compassionism beside the old basic-income or negative-income-tax rows would compare designs paid for in different ways, which breaks the fairness rule (standing guardrail 7) and would not be a real comparison. So the page needs a short new study first, not only a new layout.

## What the next session does

1. **One financing rule for every design.** Two views, side by side, each applied to all six designs:
   - *Paid by new money* (the way v5.0 reads the Source): each design's net payout is new money, less what new output backs. This is v5.0's own rule, so Compassionism's row is the released one.
   - *Paid by a flat contribution on wages*: the old comparison's rule, rerun with v5.0 Compassionism.
   Each design at equal cost to Compassionism, and at its proponents' size, as before.
2. **Rerun at 500 seeds** in the three environments, at 20 and 40 years (the ledger's step s49), split by environment so no run outlasts a session.
3. **The public costs avoided for every design** (compare step s36), with the same sourced estimates the simulation page uses.
4. **The page**: `compare.html`, built from the draft's layout, with BLEI first, the same plain sentences and 95% intervals, and a clear note on which financing rule each table uses. A "Limits and costs" section (compare step s42) says where Compassionism costs more or raises prices more than the others.
5. **Link it** from the simulation page (progress item 21) and from the walk-through.

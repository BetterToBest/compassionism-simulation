## Lessons from session 40 (save time)

- Don't edit `index.html` while a check or lineage proof is running (they read it); use a git worktree for parallel engine work.
- Run long batches from a clean worktree of a commit; write each batch's outputs in its own worktree (output files make the tree "dirty" in later manifests). Don't symlink `node_modules` into a worktree (it shows as untracked); `harness.js` doesn't need it.
- Don't put a `//` comment in the middle of an engine line when patching with string replacement: it comments out the rest of the line (this broke the PTH equity update once; the accounting test caught it).
- `pkill -f` with a pattern that matches your own shell's command line kills the shell.
- Data access from this environment: FRED (fredgraph.csv), OpenFEMA, www2.census.gov file tables and the DOL UI summary work; api.bls.gov hit its daily limit, bls.gov pages and the Census API (needs a key) are blocked.
